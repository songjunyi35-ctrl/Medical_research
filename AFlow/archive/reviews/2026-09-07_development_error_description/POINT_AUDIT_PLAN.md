# 保存点坐标与开发标签的独立核查

现有正式验证器检查了保存的Point布尔值之和。本次补充审计直接读取获授权的开发180例WT缓存标签，核对保存的平坦点坐标是否在肿瘤内，以及真值体素数是否正确。它不是新的性能试验，也不改变模型、阈值、病例或任何门。

每项实验必须先有正式RAW、RESULT和通过的VERIFICATION。先核其哈希、冻结缓存index与labels SHA、开发清单，再写审计前收据；只按dev病例索引解码180份128³二值标签，不读取训练/保护队列标签数组、影像或checkpoint，不运行模型。

对每个已保存模型的180行，独立用NumPy C-order展平标签：重算非零体素数、检查点坐标是合法整数且在范围内、重算标签该位置是否为1，与保存结果逐项匹配。空真值或非二值缓存直接失败。所有行都保留；失败报告不自动触发模型重跑。

边界：这证明给定保存坐标的命中布尔值和真值大小正确，不证明该坐标确为模型logit最大点，也不独立重建预测mask或重算交集。没有保存完整logit/预测mask，不能把本审计说成完整推理复现。读取已揭示开发标签计作重复开发访问，不称fresh/blind；0新增forward，不访问test/outer/confirmation/external。

当前先核辅助监督四个模型（720条已存点记录）；待患者采样实验完成，再核其两个候选和两个复用control（720条已存记录，其中control与前次重复）。后一审计不增加或重复模型推理。
