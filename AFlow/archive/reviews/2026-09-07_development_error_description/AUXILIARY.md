# 切除腔辅助监督：开发错误的预定离线描述

正式结果为两seed均未过门；本描述不改变该决定。仅从已保存的180 scans/78患者计数计算，0新增前向、无影像/标签数组访问。两个seed共享患者，不当两份独立验证。

全队列平均漏画比例，候选相对对照分别增加0.004729和0.004930，即平均多漏约0.47/0.49个百分点的真肿瘤体积。多画体素/真肿瘤体素的平均比例则分别减少1.40436和增加0.17751，方向不一致。这个比例可大于1，尤其在极小真肿瘤时容易被放大；它不是假阳性率，也不能由减少1.4直接推算Dice应该增加。所有模型空预测均0，排除“整例输出空”作为本次总体下降的解释。
