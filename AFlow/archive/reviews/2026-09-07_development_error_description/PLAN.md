# 开发结果的漏画/多画描述：揭示前计划

本计划仅解释两项已经注册的复用开发实验：切除腔辅助监督、患者等概率采样。不是新训练方法、次级晋级门或独立确认。每项正式RAW、RESULT和验证收据齐全后，使用保存的逐例计数离线计算，0新增前向、不读取预测数组或原始标签数组。现有训练、评测及采样方案不变。

每个seed分别与其预指定control配对，不把两seed合成156位患者。不做子组显著性检验、区间搜索、最佳组选择或病例剔除；所有组都输出，原正式全队列门仍是唯一晋级判据。

每例的漏画比例=(真肿瘤体素−重叠体素)/真肿瘤体素；多画比例=(预测体素−重叠体素)/真肿瘤体素。两者都以真肿瘤大小为分母，前者0到1、后者可能超过1；不能把后者冒称假阳性率或precision。空预测漏画比例为1、多画为0，仍纳入并单独计数。Dice不等于这两个均值的简单线性组合。

输出每臂扫描平均Dice、患者内先平均再患者等权Dice、Point命中数、空预测数、两种比例的扫描平均，以及配对差和Dice改善/下降/持平数。

预先固定五组：全180扫描；原生肿瘤体积≤18874、(18874,40435]、(40435,80247]、>80247体素。切点来自fit684四分位描述，不来自开发分数或开发分位数；开发组数无需相等。只读取冻结体积工件中的dev病例，分组不进入训练。每组列扫描/患者数；同患者不同扫描可跨组，组患者数不能相加当独立患者。

解释范围：可描述候选收益/损失与漏画、多画及体积的伴随变化，不能证明机制因果或挽救失败的全队列门。即使某组改善，也不自动授权阈值、损失、采样混合、epoch、seed、test或external新访问。
